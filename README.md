# 阿里母婴电商数据分析项目

本项目基于阿里巴巴天池提供的母婴电商数据集，使用Python进行数据清洗、探索性分析和可视化，旨在挖掘用户购买行为、商品销售趋势以及不同用户群体的消费特征。

## 项目背景

随着二胎政策的开放，母婴市场持续扩大。通过分析真实的母婴电商交易数据，可以帮助商家更好地理解用户需求，优化产品策略，并制定更精准的营销方案。

本项目使用的数据来自阿里云天池大赛，包含约 **3万条** 交易记录和 **近千条** 用户信息。

## 数据集说明

项目使用两个核心数据集：

- **`tianchi_mum_baby_trade_history.csv`**：交易记录表
  - `user_id`: 用户ID
  - `auction_id`: 商品ID
  - `category_1` / `category_2`: 商品的一级和二级类目ID
  - `buy_mount`: 购买数量
  - `day`: 交易日期

- **`tianchi_mum_baby.csv`**：婴儿信息表
  - `user_id`: 用户ID
  - `birthday`: 宝宝生日
  - `gender`: 宝宝性别 (0: 女, 1: 男)

## 分析流程与洞察

### 1. 数据清洗与预处理

- 将交易日期 (`day`) 和宝宝生日 (`birthday`) 转换为日期时间格式。
- 剔除了 `buy_mount` 异常值（大于189）和 `gender` 无效记录，确保数据质量。
- 计算了宝宝在交易时的**年龄（`age`）**，用于后续的年龄维度分析。
- 合并交易表和婴儿信息表，为深度分析做准备。

### 2. 整体销售趋势分析

#### 年度与季度销售趋势
- **年度销量**：2014年销量达到顶峰，远超其他年份，可能与“二胎政策”及平台促销活动有关。
- **季度趋势**：销售呈现明显的**年底冲量**趋势，每年第四季度（尤其是双11、双12大促期间）是销售高峰。
- 从月度数据看，**11月和12月**的销量远高于其他月份，说明电商大促对母婴产品消费有极强的拉动作用。

![年度销量](./images/yearly_sales.png)
![季度销量趋势](./images/quarterly_sales.png)

#### 月度销售明细
- 通过2014年1月的日销量图可以看出，日常销售平稳，但在大促节点（如元旦）会出现小高峰。

![日销量](./images/daily_sales.png)

### 3. 商品类目分析

- **一级类目**：`50008168` 和 `50014815` 是销量最高的两个大类。
- **二级类目**：`50013636`、`50010558` 等是热销子类目，说明用户对特定品类有高度集中的需求。
- 一级类目 **`50014815`** 虽然销量很高，但其下的二级类目数量并不是最多的，说明该类目下的商品集中度很高，可能存在爆款。

![大类销量](./images/category_sales.png)
![二级类目分布](./images/category2_distribution.png)

### 4. 用户画像分析 (性别与年龄)

#### 性别分布
- **用户性别**：在合并数据集中，女性用户（宝宝为女孩的妈妈）的购买频次略高于男性用户（宝宝为男孩的妈妈）。
- **消费偏好**：
  - 当宝宝是**男孩**时，家长们更倾向于购买类目 `50008168` 和 `50014815` 的商品。
  - 当宝宝是**女孩**时，购买偏好集中于 `50014815` 和 `50008168`，但 `50014815` 的占比显著高于男孩组，显示出不同性别宝宝在商品需求上的差异。

![用户性别分布](./images/gender_distribution.png)
![男孩消费类目](./images/male_category_pie.png)
![女孩消费类目](./images/female_category_pie.png)

#### 年龄分布
- 用户的宝宝年龄主要集中在 **0.25岁 到 2.3岁** 之间（25%分位数至75%分位数），表明新手父母（宝宝0-2岁）是母婴消费的核心群体。
- 平均年龄约为 **1.54岁**，中位数为 **1.25岁**，这说明大部分用户的宝宝尚处于婴儿期。

## 结论与建议

1.  **营销策略**：应重点关注**每年的第四季度**，特别是**双11和双12**期间，加大广告投入和促销力度，以抓住销售高峰。
2.  **选品策略**：应重点发力**一级类目 `50008168` 和 `50014815`**，并深入研究其下的热销二级类目（如 `50013636`），打造或引进爆款产品。
3.  **用户运营**：目标用户群体应锁定在**宝宝年龄为0-2岁的新手父母**。可针对不同性别宝宝的家长，设计差异化的推荐策略和内容营销。
4.  **数据驱动**：建议持续监控月度及日度销售数据，评估促销活动的实际效果，实现精细化运营。
